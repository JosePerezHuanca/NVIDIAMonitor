# Монитор NVIDIA

Это дополнение позволяет отслеживать различные параметры видеокарт NVIDIA, такие как название, используемая память, свободная и общая память, энергопотребление, температура и многое другое.

## Горячие клавиши

Примечание: Некоторые информационные параметры могут быть несовместимы или не поддерживаться в зависимости от видеокарты.
Все перечисленные ниже сочетания клавиш можно настроить в категории жестов ввода/NVIDIAMonitor. Двойное нажатие сочетания клавиш копирует информацию в буфер обмена.

- NVDA + alt + g: Объявляет название/модель графического процессора.
- NVDA + alt + u: Объявляет UUID графического процессора.
- NVDA + alt + v: Объявляет версию драйвера.
- NVDA + ctrl + alt + v: Объявляет версию BIOS.
- NVDA + alt + 1: Объявляет загрузку графического процессора.
- NVDA + alt + 2: Объявляет загрузку памяти.
- NVDA + alt + 3: Объявляет свободную память.
- NVDA + alt + 4: Объявляет объём используемой памяти.
- NVDA + alt + 5: Объявляет общий объём памяти.
- NVDA + alt + 6: Объявляет температуру графического процессора.
- NVDA + alt + 7: Объявляет потребление электроэнергии.
- NVDA + alt + 8: Объявляет ограничение мощности.
- NVDA + alt + 9: Объявляет количество процессов CUDA.
- NVDA + alt + 0: Объявляет объём памяти, используемый процессами.
- NVDA + ctrl + alt + 1: Объявляет скорость вентилятора.
- NVDA + ctrl + alt + 2: Объявляет тактовую частоту графического процессора.
- NVDA + ctrl + alt + 3: Объявляет максимальную тактовую частоту графического процессора.
- NVDA + ctrl + alt + 4: Объявляет тактовую частоту SM.
- NVDA + ctrl + alt + 5: Объявляет максимальную тактовую частоту SM.
- NVDA + ctrl + alt + 6: Объявляет тактовую частоту памяти.
- NVDA + ctrl + alt + 7: Объявляет максимальную тактовую частоту памяти.
- NVDA + ctrl + alt + 8: Объявляет пропускную способность передачи.
- NVDA + ctrl + alt + 9: Объявляет пропускную способность приёма.
- NVDA + ctrl + alt + 0: Объявляет состояние питания.


## Журнал изменений

### Версия 2.1

- Исправлена проблема с прямыми вызовами pynvml.

### Версия 2.0

- Совместимость с NVDA 2026.1.
- Начиная с этой версии, дополнение при работе с последней версией NVDA выполняет прямые вызовы к библиотеке pynvml вместо использования внешнего инструмента.

### Версия 1.0

- В скрипт поиска информации были внесены многочисленные изменения, исправления и улучшения.
- Теперь ошибки записываются в файл NVIDIAMonitor.log, расположенный в папке конфигурации NVDA.
- Совместимость с NVDA 2025.1.
- Некоторые существующие сочетания клавиш были переназначены.
- Добавлены новые сочетания клавиш:
  - UUID графического процессора: NVDA + alt + u
  - Версия драйвера: NVDA + alt + v
  - Версия BIOS: NVDA + ctrl + alt + v
  - Загрузка памяти: NVDA + alt + 2
  - Ограничение мощности: NVDA + alt + 8
  - Память, используемая процессами: NVDA + alt + 0
  - Максимальная тактовая частота графического процессора: NVDA + ctrl + alt + 3
  - Тактовая частота SM: NVDA + ctrl + alt + 4
  - Максимальная тактовая частота SM: NVDA + ctrl + alt + 5
  - Тактовая частота памяти: NVDA + ctrl + alt + 6
  - Максимальная тактовая частота памяти: NVDA + ctrl + alt + 7
  - Пропускная способность передачи: NVDA + ctrl + alt + 8
  - Пропускная способность приёма: NVDA + ctrl + alt + 9
  - Состояние питания: NVDA + ctrl + alt + 0

### Версия 0.2

- Теперь, при двойном нажатии сочетания клавиш, информация копируется в буфер обмена.
- Различные улучшения и оптимизации.

### Версия 0.1

- Начальная версия дополнения.
